# OPS/OS

HTML playtest of an 8-minute shift. Not the Godot game.

Open `index.html` in a browser. Click the canvas once so keys bind.

## Keys

- `1` `2` `3` — workspaces (Power / Mining / Security)
- `s` `h` `m` — SAFE / HIGH / MAX
- `[` `]` — step mode
- `tab` — next window on this workspace
- `enter` — repair (when Repair is focused)
- `q` — close focused

## Sit a shift

Boot is workspace 2, miner SAFE, clock 08:00.

`h` for HIGH. A filter clog should show. `tab` to repair, `enter` to clear. Ignore it and the cascade names what you let die.

Clock-out with the site up is a win. SITE KILL is a loss. Credits are the score.
